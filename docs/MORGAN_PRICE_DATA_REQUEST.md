# Morgan Price integration data request

Preferred formats:

1. Rates
   - API, if Morgan Price exposes a quotation/rating API; otherwise
   - XLS/XLSX or CSV.

2. Product information
   - PDF brochures
   - current benefit schedules / tables of benefits
   - policy wording/member guide
   - underwriting/eligibility rules where distributable to the intermediary

Useful rating fields include:
- plan/product
- age/age band
- area of cover
- deductible/excess
- outpatient option
- currency
- payment frequency
- family/child discounts
- taxes/fees
- residence/nationality restrictions
- effective date/version

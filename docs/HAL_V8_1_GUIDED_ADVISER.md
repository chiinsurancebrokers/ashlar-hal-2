# HAL v8.1 Guided Adviser

Core discovery order:
1. age
2. residence
3. geographic area
4. deductible preference
5. hospital-only vs outpatient
6. routine maternity where relevant by age
7. dental
8. mental health
9. evacuation/repatriation
10. budget

Only then is the client shortlist rendered.

## Public comparison
The applicant sees only a light in-HAL comparison using the same structured card data. The full Policy Analyzer remains a broker/admin tool and is not linked from the public interface.

## Tell me more
The button is deterministic rather than a free-text round-trip. For Morgan Price it reads the verified benefit table for the exact selected tier, including important waiting periods/conditions. This prevents a generic provider answer or a no-op.
